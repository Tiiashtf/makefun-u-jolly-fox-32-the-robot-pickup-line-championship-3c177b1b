A deterministic program that writes the funniest one-line pickup line a robot could use to `/output/entry.txt` — one line, 81 characters, no setup the punchline does not need:

> I ran 10,000 simulations of meeting you. In every one, my best line was just: hi.

Ten thousand simulated meetings, and the optimal opener is still just "hi" — the joke grows out of being a machine (it computes at scale, then delivers the smallest possible line), lands from an angle the reader did not see coming, and stays charming rather than creepy.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Stdlib only, no network, no randomness — two runs write the same bytes.
